# ダッシュボードのレイアウト変更（11/7）

## 変更点

#### 1.項目選択画面
現在以下の項目と役割が存在する。
- 通信：今まで観測したIPの国などを表示
- 正規化ログ：正規化したログをダウンロード
- 生ログレビュー：Rawログをダウンロード
- AIレポート：AIが解析したレポートをダウンロード
- 日次解析・運用：ログ収集の完了・未完了を確認
- ホスト監視：各VPSやサーバーの容量を監視する

変更後は以下のような項目と役割を実装する。
- 通信：変更なし
- ログ：解析対象のログをダウンロード
- AI解析：ここでは、日付とログを選択することでAIに解析を依頼できて帰ってきたファイルをダウンロード可能にする
- 日次解析・運用：変更なし
- ホスト監視：変更なし

#### 2.公開ログについて
以前はCanonicalとRawを分けて表示していたが、正規化ルール変更にともなって分けずに表示する方針を取る。

#### 3.AI解析について
AI解析依頼時にログを取得する必要がある。ログ項目と同じようなレイアウトを採用する。
解析対象を見分けるために、IDを用いる。

VPS1件ずつとバックエンド2件を含めて合計6件を選択し、AIへ依頼する。
AI解析の実行依頼はダッシュボード上で行い、APIを使った処理自体はWSで行う。
AI解析により出力されるファイルはAI解析画面にてダウンロードさせる。
