# VPS1構築作業レポート(10/6 13:30~21:30)

## 構築内容

VPS1を、SuricataとCowrieを採用し、ハニーポットとログ収集を行う機能を実装した。収集したログは正しい形式へ正規化し、Wazuh Agentを通じてLinuxWSへ転送する構成である。

## 実施内容

- Suricata 8.0.7を導入し、ネットワーク監視とEVE JSONログ出力を有効化した。
- Cowrieをsystemdサービスとして管理し、SSHハニーポットを22222/tcpで稼働させた。
- SuricataログおよびCowrieログを、機微情報を含まないJSON形式へ正規化するサービスを構築した。
- 正規化ログをWazuhAgentでLinuxWSへ転送した。
- LinuxWS側で、スキーマ検証とイベント分類を実施する中央処理経路を構築した。
- SSH、UFW、Swap、ログローテーション、自動起動、Suricataルール自動更新を設定した。
- VPS1に残っていた旧WazuhManager、Indexer、Dashboard、Filebeatを撤去し、不要な公開待受と一時的なファイアウォールルールを削除した。

## 確認結果

SuricataおよびCowrieの実イベントについて、以下の経路を確認した。

**VPS1 → Wazuh Agent → LinuxWS Wazuh Manager → スキーマ検証 → 分析候補イベント**

検証では、不正JSON、event_id重複、隔離対象、ルーティングエラーはいずれも0件だった。また、Cowrie、Suricata、両normalizer、WazuhAgentはすべて自動起動かつ稼働中であり、再起動回数は0回だった。

## 構築後状態

- Suricata：稼働中
- Cowrie：稼働中
- Suricata normalizer：稼働中
- Cowrie normalizer：稼働中
- Wazuh Agent：LinuxWSへ接続済み
- UFW：有効、不要なWazuh受信ルールなし
- 旧Wazuh Manager関連機能：撤去済み
- 空きストレージ：約157GB
