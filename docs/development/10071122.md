# VPS2の動作確認と通信確認（10/7 9:00-10:30）
DionaeaWebを動かすハニーポットの動作を確認した際の内容とLinuxWSまでのログ経路の確認をした際の内容を示す。

## 現状
VPS２錠ではDockerでdionaea-webコンテナが稼働中であり、http/httpsサービスとして80と443ポートを公開している。

WazuhAgentはLinuxWSに接続されている。

## 調査結果
### WazuhAgentについて
WazuhAgentはLinuxWS上でActive状態を確認し、AgentID・名前にも異常はなかった。

### ログ経路について
ログ経路として以下の2つのND JSONファイルが生成されていた。
- /log/autosoc/dionaea-connections.ndjson
- /log/autosoc/dionaea-http.ndjson

これらはroot:wazuh、権限640で管理されいて、Agentが読み取り可能だった。

Jsonの品質検査では、両ファイルとも不正Jsonは0件であり、event_idの重複も0件だった。

LinuxWS側では、VPS2のイベントがWazuhのalerts.jsonに到達していることを確認した。

さらに、中央Schema検証後の**valid-events.ndjson**にVPS2イベントが記録され、httpイベントは**analysis-candidates.ndjson**に、接続イベントは**ied-events.ndjson**に振り分けられていることを確認した。

## まとめ
以上のことからVPS2については以下の経路が正常に成立していることが確認できた。

Dionaea Web → canonical NDJSON → Wazuh Agent → LinuxWS Wazuh Manager → schema validation → event gate

VPS2は、DionaeaWebハニーポットとしてLinuxWSまでの通信検証は完了した。
