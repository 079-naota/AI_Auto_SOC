# 正規化ルール見直しによる解析ルーティン

## 1.事前確認
ダッシュボードの日次運用画面から解析対象日のログが準備できているのかを確認する。
準備できているなら手順２へ進み、準備できていないならエラーの原因究明・対処を行う。

## 2.手動解析対象の収集
ログページに移動し、センサー・観測日を指定し、各VPS1件ずつ、Backendは2件をローカルにダウンロードする。

## 3.解析スクリプトによる手動解析
手順２でダウンロードしたログを解析する。
まずは、ログの完全性を調べるためにハッシュ値で確認する。
完全性を確認できたらハニーポット別のスクリプトを用いて解析する。
解析後、把握した内容を元にレポートを作成する。

## 4.AI解析の実行
手動解析を行なった後に、手動解析の元となったログをAIに解析させレポートを生成させる。

## 5.手動・AI解析結果の保管
生成されたレポート、解析対象ログ、手動解析レポートの3つをセットにし、保管する。
