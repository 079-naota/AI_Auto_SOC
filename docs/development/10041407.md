# LinuxWorkstaionとVPS2の作業レポート(~10/4)

## 大まかな役割
VPS2では以下の役割を持っている
- Dionaea 80/443 portで通信を受け取る
- 接続情報とHTTPリクエストを保存する
- HTTPの本文はVPS2に保存する
- 他のメタデータをLinuxWSに送信する

## VPS2で作成した機能
### アカウントとSSHの分離
既存の管理者アカウントと作業管理アカウントの分離を行った。
管理者ではパブリックIP経由のパスワード認証、作業管理アカウントはVPNの公開鍵認証のみを利用する。
作業管理アカウントにはsudo権限を付与して、通常のDionaea・Wazuh・Docker管理をアカウントで行えるようにした。

### 接続情報の交換
- dionaea-exporter.py
SQLiteのconections表を読んで、接続イベントを共通形式のNDJSONへ変換する

- connections.ndjson
変換後の接続情報であり、WazuhAgentがこのファイルを監視する

- /autosoc/
最後に変換したIDなど、再処理や重複を防ぐ状態情報を保存する

- dionaea-exporter.service
SQLiteから接続情報を抽出するoneshotサービス

- dionaea-wxporter.timer
上記サービスを1分間隔で実行する

### HTTPリクエストの変換
- http.ndjson
HTTPの抽出結果であり、Wazuhへ送るのはこの安全なメタデータであり、ペイロード原本ではない

- controlled-test-ids.txt
自分で実施した制御テストのIDを登録するファイル。
この登録簿に一致した通信だけを controlled_test とする

- dionaea-http-state.sqlite
処理済みbistreamを管理し、同じファイルの重複処理を防ぐ

- autosoc-dionaea-http-exporter.service
bistreamを解析してHTTP NDJSONを生成する

- autosoc-dionaea-http-exporter.timer
1分間隔で新しいbistreamを処理する

### WazuhAgent
#### ossec.conf
VPS2のWazuhAgent設定
現在は２ファイルを監視している
- dionaea-connections.ndjson
- dionaea-http.ndjson

### 容量監視
#### autosoc-storage-check.sh
ディスクの使用率、空き容量、bitstream件数と容量を確認する
- 75%以上：警告
- 85%以上：重大
- 空き5GB以下：重大

## Linux WorkStationでの機能
### Wazuh中央基盤
以下のWazuhコンポーネントを追加した。
- Wazuh Manager
- Wazuh Indexer
- Wazuh Dashboard
- Filebeat
VPS2のWazuhAgentはLinuxWSへ接続済である。

### Dionaea検知ルール
VPS2から純真したイベント判定ルールは以下の通りである。
- 100200：Dionaea接続イベント
- 100201：DionaeaHTTPイベント
- 100202：制御HTTPテスト
- 100203：HTTPポートへの以上・バイナリ通信
制御POSTでの試験ではVPS2とLinuxWSで同一のEvent_idが確認された。

### 共通ログスキーマ

- @timestamp
- schema_version
- event_id
- event
- sensor
- labels
- source
- destination
- network
- artifact
- http 
- dionaea


## エラーハンドリング
### 作業対象ホストの取り違え
rules.xmlをVPS2で開こうとした際、VPS2にはWauzhManager用ルートディレクトリがないためエラーになった。
これにより役割の確認し、次のように分離した。
- VPS2：収集・変換・転送
- LinuxWS：ルール判定・スキーマ検証・分類

### 正規HTTP以外の通信
HTTPポートに来た11件を調べると、正規HTTPは制御POSTの1件だけで、残りはバイナリや以上形式の結果だった。
単純にHTTPメソッドとして処理すると文字化けした値になるので、抽出プログラムで次のように分離した。
- vaild_http
- malformed_or_binary
異常通信も攻撃観測上重要のため、捨てずにSHA-256とサイズを保存する。
